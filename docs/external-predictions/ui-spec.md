# 外部预测源 — UI 设计规范

- 版本：1.0（2026-09-18）
- 依据：`prd.md` 1.0、`architecture.md` 1.0
- 原则：复用现有视觉与交互（panel 卡片、form-field、badge、modal），不做全站重排，不引入前端框架。管理员入口与用户入口分离；不把上游 `confidence` 呈现为本地命中率；不暴露连接配置/原始整批数据。

## 1. 管理后台（admin.html + admin.js）

### 1.1 新增 panel：“外部预测源”

- 位置：连续 panel 流中，“任务状态”之后、“竞彩足球数据健康”之前（运行状态类信息聚拢在顶部）。复用 `<section class="panel">` + `panel-header` + `panel-subtitle` 结构。
- 标题：“外部预测源”；副标题：“管理员维护外部预测 API 来源与开放模型，采集由后端统一执行，用户方案共享采集结果。”
- 页头锚点：沿用现有页头快速导航的写法（若现有页头为 panel 列表锚点则同步追加；如无锚点体系则不加，保持一致）。

### 1.2 panel 内容结构（自上而下）

1. **来源列表**（每来源一张内联卡片，复用用户列表的移动端卡片模式 `adminXxxBody`/`adminXxxCards` 双容器）：
   - 行字段：名称＋插件徽标（`jnd28`）、基址、启停开关（沿用 toggle-enabled 按钮样式）、采集间隔、状态徽标：
     - 绿“正常”（last_success_at 距今 < 2×interval）
     - 黄“等待更新”（正常但本期未产出新期号）
     - 红“异常”（last_error 非空且晚于 last_success_at），悬停/展开显示 last_error 文本与时间
     - 灰“已停用”
   - 次行：最近尝试/成功时间、最近目标期号、模型总数/开放数、最近批次数。
2. **来源操作**（行内按钮组，沿用现有小按钮样式）：`测试连接`、`刷新目录`、`模型目录`（展开）、`编辑`（名称/基址/间隔的行内小表单或复用 modal 风格浮层）。
3. **模型目录子视图**（点“模型目录”展开，默认收起）：
   - 表格（桌面）/卡片（移动）：显示名、model_key（等宽字体小号）、开放开关、最近出现时间；上游近期未再见到的模型显示灰徽标“最近未见”。
   - 顶部批量操作：`全部开放`、`全部关闭`、说明文字“开放后用户方可绑定该模型；关闭不影响已有历史。”
4. **最近采集批次**（每来源最近 5 条）：期号、版本号、获取时间、模型数/异常模型数；版本 >1 的行加黄徽标“上游修订”。
5. **空态/错误态**：无来源时显示引导文案＋“添加来源”按钮（预填 plugin_key=jnd28 默认值表单：名称、基址、间隔，创建后提示“来源默认停用，请先测试连接并开放模型”）。
6. 任务状态 panel 的聚合数据增加一行“外部采集线程：运行中/已停用/心跳时间”（复用现有 scheduler 渲染）。

### 1.3 交互约束

- 所有写操作（启停/编辑/刷新/开放模型）沿用现有 confirm + fetch + 局部刷新模式；失败用现有 toast/错误条展示后端 `error` 文案。
- “测试连接”结果以行内结果条展示：成功（模型数、目标期号、耗时）或失败原因（超时/响应超限/解析失败），不写库。
- 普通用户访问 admin API 被拒时（403），页面照常显示无权限提示，不重试循环。

## 2. 用户前台（dashboard.html + app.js）

### 2.1 新建/编辑方案 modal（`#predictorModal`）

- `engineType` select 增加 `<option value="external">外部预测</option>`；hint 更新为“AI 模型适合提示词驱动；机器算法适合低成本稳定运行；外部预测使用管理员接入的公开预测源，无需 API Key。”
- **external 专属区块** `#externalEngineField`（span-2，紧随“机器算法”区块之后，仅 external 时显示）：
  - `#externalSourceId` select：启用中的来源（选项文字＝来源名）；无可用来源时显示禁用选项“暂无可用外部来源，请联系管理员”。
  - `#externalModelKey` select：联动所选来源的开放模型（选项文字＝模型显示名，副文 model_key）；来源切换时重拉/重筛。
  - hint：“模型列表由管理员开放；绑定修改只影响之后的预测，历史记录保留当时的模型与结果。”
- **引擎切换联动**（`updateLotteryForm` external 分支）：
  - 隐藏：`algorithmField`、`apiUrlField`、`modelNameField`、`apiModeField`、`apiKeyField`、`temperatureField`、`dataInjectionModeField`、提示词区块与提示词助手按钮、历史窗口（外部方案不使用历史窗口；后端固定值）。
  - 目标 checkbox：仅显示 大小/单双/组合 三项（**隐藏并取消勾选 number**，不沿用“number 永远保留”的固定逻辑）；至少勾选一项。
  - 主玩法/收益玩法选项收敛到已勾选目标。
  - `predictionMethod`、名称、启停、分享设置照常显示。
- **编辑回填**（`fillFormFromPredictor` external 分支）：回填 source/model 选择；AI 字段留空即“保持原值”的语义不适用于 external（后端忽略这些字段），提交时 payload 不携带 AI 专属键。
- **测试连接按钮**：external 时隐藏（无用户侧连通性概念），或改为禁用态提示“外部来源由管理员测试”。

### 2.2 方案列表/详情/历史

- 引擎徽标：external 显示“外部预测”徽标（复用现有 engine 徽标样式，新增一种配色）；徽标旁小字显示“来源名 · 模型名”。
- 历史列表：external 行显示模型名与来源（取自 provenance）；reasoning_summary 已由后端生成“外部来源 JND·模型名 期号 xxx”，正常渲染即可。
- 统计区：命中率为本地结算口径，文案不变；如展示 confidence，标注“上游评分”字样，且不得出现在命中率图表轴/图例中。
- **异常状态文案**（方案详情/列表状态条）：
  - 来源停用：“外部来源已停用，等待管理员恢复后才会产生新预测。”
  - 模型未开放/已下架：“该模型未开放或已下架，可改绑其他模型。”
  - 等待更新：“本期预测尚未由来源发布（正常等待，无需处理）。”
  - 数据来源：`GET /api/predictors` 返回的方案对象新增 `external_status` 字段（`ok|source_disabled|model_unavailable|waiting|stale`）＋ `external_status_message`。

### 2.3 导出与分享（公开分享区）

- 现有导出连接入口增加权限说明文案：“分享等级为『仅统计』的方案，匿名将无法读取信号导出。”
- 新增“导出授权 Token”子区块（仅方案所有者可见）：
  - 列表：标签、前 8 位（`pts_ab12…`）、创建时间、最近使用时间、状态（生效/已撤销）。
  - 操作：`生成 Token`（弹输入标签，成功后一次性展示完整 token＋复制按钮＋警示“仅显示一次”）、`撤销`。
  - 使用说明折叠块：“下游请求头示例：`Authorization: Bearer <token>` 或 `X-Export-Token: <token>`（pc28touzhu 来源配置 fetch.headers 可直接填写）。”
- 空态：无 token 时显示“未创建授权 Token。公开分享（记录/分析）的方案无需 Token 即可导出。”

## 3. 文案与禁用规则

- 全部新文案使用中文，禁用态均有原因（禁止无声禁用）。
- 不出现：API Key/提示词必填标记、`confidence` 表述为“命中率/准确率”、来源基址等连接配置展示给普通用户。
- 外部方案统计与 AI/机器方案同口径，页面不新增“上游 100 模型”之类与单个方案无关的信息。
